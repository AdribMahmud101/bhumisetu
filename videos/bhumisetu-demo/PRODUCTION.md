# BhumiSetu demonstration film

This is a 90-second, 1920×1080, 30 fps product demonstration built with the installed HyperFrames 0.8.171 plugin. The final delivery has Soniox Priya Bangla narration and burned-in Bangla captions. The original muted export is retained for editing.

## Editorial evidence

- Application: `https://bhumisetu.adribmahmud.workers.dev`.
- Every product screen is captured from the actual running application. No API response was intercepted, mocked or replaced.
- P1: an existing fictional Bangla Khatian image was uploaded through the officer intake. The real OCR response returned editable fields. The video includes officer corrections against the source, including Khatian 105 and 0.15 acre converted to 15 decimals. The intake was aborted after capture; no new parcel was confirmed.
- P2: the existing altered synthetic deed 502/2021 was uploaded through deed verification. Real extraction returned 25 decimals; comparison with the reviewed deed's 12 decimals produced the shown mismatch.
- P3: live fictional parcel `LND-MOCK-001` had 20 recorded decimals, two 12-decimal deeds, a related mutation and a 65/100 rule indicator at capture. The film explains the area conflict and source evidence rather than describing the indicator as a fraud probability.
- P5: the actual exported parcel QR was downloaded and uploaded to the citizen search, which opened the same published record. The print view was generated by the real print button and saved through browser PDF output.
- The audit scene shows a real historical old/new dag correction on the fictional record. It is not presented as the same unconfirmed intake as the preceding scene.
- The short opening and closing are editorial motion graphics. They use the app's captured landmark mark, Bangla branding and green palette.

## Edit decisions and timing

`SOURCE_RANGES.json` identifies the original captured clips, source intervals and shortened provider waits. Both shortened waits are labeled in the picture. Presentation clips use one-second keyframes for reliable seeking; recorded interactions retain their original speed. Crops magnify actual screenshots without changing their values. Raw session recordings and authenticated browser state stay under the repository's ignored `.local/video/` and `.local/` directories.

`TIMING.json` is the picture and subtitle timing authority: eight scenes, exactly 90 seconds, 19 disjoint Bangla caption intervals and eight separate speech windows. `captions.bn.srt` contains the same caption text as the film. Priya generated each line separately. `VOICE_TIMING.json` records each actual line duration, placement, and the provider pacing for the opening and overview, plus a 4.5% pitch-preserving finish on the overview. Every recorded line ends inside its speech window; the inter-scene gaps remain silent.

## HyperFrames workflow

The installed plugin's product-launch workflow supplied capture, frame-preset adaptation, registry discovery, local media registration, preview, checks and final rendering. The brand was captured from the app; `frame.md` is the adapted `blue-professional` preset. Browser staging, focus-camera and transition primitives were installed and consulted before authoring the film's seekable GSAP camera/settle motion.

The composition uses one monolithic root timeline so source clips, captions and global camera moves share explicit global timestamps. HyperFrames reports architecture advisories for that choice and a repeated source image. Runtime, layout and contrast checks must pass before delivery; this is separate from those non-blocking architecture advisories. Intentional screen crops are expected.

## Edit or reproduce

Open the project in HyperFrames Studio, or edit `scripts/build-film.py` and run:

```bash
python scripts/build-film.py
bun run check
bun run dev
```

`package.json` routes these commands through the installed, version-pinned plugin launcher. The persistent review preview is `http://localhost:3031/#project/bhumisetu-demo`.

`scripts/prepare-media.py` regenerates presentation clips from the ignored original recordings. `scripts/capture-app.ts` performs real application capture and therefore needs the ignored officer session and synthetic sample files from this workspace; it does not contain credentials.

For plugin-owned commands, use its launcher rather than updating standalone skills:

```bash
node "$HOME/.codex/plugins/cache/hyperframes/hyperframes/0.8.171/skills/hyperframes/scripts/plugin-cli.mjs" render --fps 30 --quality delivery --output renders/BhumiSetu_90s_Bangla_Muted.mp4
```

Recheck duration, dimensions and captions after any final encode; the muted master has no audio stream and the Priya delivery has one AAC stream. Decode and inspect representative frames from the MP4 itself; a browser preview alone does not prove the delivery pixels.

## Priya voice version

Soniox model `tts-rt-v2`, language `bn`, voice `Priya`. The key is read from `SONIOX_API_KEY` only; the ignored `.local/soniox.env` and raw generated takes do not belong in a submission. Rebuild from the repository root with `uv venv .local/soniox-venv` and `uv pip install --python .local/soniox-venv/bin/python soniox==2.10.0`, followed by `SONIOX_API_KEY` in the environment and `.local/soniox-venv/bin/python videos/bhumisetu-demo/scripts/create-priya-version.py` from the repository root. The script reuses existing takes, validates every window, and creates the aligned WAV and voiced MP4.

`VOICE_VALIDATION.json` confirms the final narrated export: exactly 90 seconds, 2,700 H.264 frames at 1920×1080/30 fps, one AAC audio stream, eight non-overlapping lines inside their speech windows. The delivered audio track measures −18.4 dB mean and −1.5 dB peak. The original source video remained visually unchanged.
